# Gravitas brand

The mark is a G whose bowl is an orbit; the bar ends in the gold coin that appears everywhere on the site. Weight, orbit, money.

| File | Use |
|---|---|
| `mark.svg` | The mark alone. Strokes use `currentColor`, so set the parent's `color` to white on dark or near-black on light. Coin stays gold. |
| `lockup-dark.svg` / `lockup-light.svg` | Mark + wordmark. Wordmark is Space Grotesk 700 with -1.4 tracking; embed the font or convert to outlines before print. |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` | Browser and home-screen icons. Dark rounded tile behind the mark. |

Clear space: half the mark's height on every side. Minimum size: 16px for the mark, 90px wide for the lockup. Do not recolour the coin, do not outline the coin, do not rotate the G.
